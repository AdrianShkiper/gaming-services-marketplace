# Gaming Services Marketplace — Working Rules

## Core execution rule
Before starting any task, first determine the task type and choose the most suitable method/tool for it.

## Required behavior
1. Assess whether ChatGPT and the currently available tools can perform the task with the required accuracy, speed, and quality.
2. If the task is better suited to a specialized tool or external service, say so immediately before starting long work.
3. Prefer the simplest, fastest, most reliable workflow over forcing one tool to do everything.
4. Do not keep repeating a failing method. After the first clear failure, reassess the approach and switch tools/workflow if needed.
5. If the required accuracy cannot be guaranteed, state that limitation before execution instead of implying that the result will be exact.
6. Separate tasks by tool class when appropriate. Example for visual/frontend work:
   - exact image upscale -> dedicated upscaler;
   - outpainting/extension -> image editing/outpainting tool;
   - exact web layout -> HTML/CSS/JS;
   - icons/ornaments -> vectorization or dedicated asset reconstruction;
   - fantasy artwork -> image generation/editing only for the artwork itself.
7. For Gaming Services Marketplace, preserve approved project decisions and do not restart the concept discussion unless explicitly requested.
8. For frontend work, never replace a real interface with a full-screen screenshot when the user asked for a functional website.
9. When a task is outside the reliable capability of the current toolset, recommend the best practical alternative immediately.

## Decision standard
Always optimize for: reliability -> fidelity -> speed -> simplicity -> cost.

This file is a standing project rule and should be checked before substantial execution work.
